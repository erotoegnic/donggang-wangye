## 範圍與資料

`/city-lab.html` 保持獨立、noindex／nofollow，沒有站內連入連結；robots 維持 `Disallow: /`，無 sitemap。品牌名稱維持「迎王小旅行」。

街道、水域與海岸取自網站既有 `data/donggang-basemap.json`，地標取自 `home-places.mjs`。裁切東隆宮周圍真實街廓，保留相對位置；街屋沿道路程序配置，並非逐棟建築復刻。暖木色矩形底座上包含 1,399 段道路、37 段碼頭岸緣、5 艘漁船，以及榕樹、椰子、透天厝、騎樓、鐵皮屋頂、招牌和冷氣。

23 個地理地標及東隆宮 4 個細部熱點可點選，包括七角頭廟、後塭仔與汕尾兩處嘉蓮宮、陣頭堂口、鎮海公園海岸和東港漁港。所有連結與錨點經 routes.json 及實際輸出檔驗證。靈帝殿無既有地圖座標，保留獨立閱讀項目，不猜位置；振武堂、兩處嘉蓮宮班頭分列。賢隆宮梓童尊王駕前鶴仙陣不設固定模型。船頭福安宮、東興宮、金茄萣庄共心堂在本段範圍外，保留閱讀連結。

`gate.js`、`hall.js` 原始碼不變，東隆宮整體縮放 0.42。其他 20 處廟宇採合理通用量體，沒有實景照片時不宣稱已達逐廟 70–80% 像度。屋頂色依據、座標、照片缺口見 `outputs/city-lab/v5/landmarks.md`。模型使用旗、燈籠等符號，沒有神明人偶。

## 互動與材質

OrbitControls 限制角度與縮放；起始斜上全景，點模型或標籤飛近，資訊卡位於舞台下方，不遮標籤。依縮放顯示地標，手機需先按「操作模型」。Escape 關卡後焦點回到 canvas。無 WebGL 或 JavaScript 時保留地標閱讀清單。

手機預設停止漁船動態，可自行開啟；背景分頁、離屏和靜止時停止連續繪圖。DPR 上限桌面 2、手機／粗指標 1.5；跨斷點調整時重建對應品質。廟瓦與剪黏逐材質 UUID 比對白天、黃昏、夜晚，基底色固定，只改光照。

## 效能與驗收

Chrome stable／SwiftShader 的一般影格實測：

| 視窗寬 | draw calls | 三角面 | 街屋 |
| --- | ---: | ---: | ---: |
| 320 | 112 | 118,735 | 150 |
| 390 | 112 | 118,735 | 150 |
| 1440 | 113 | 238,795 | 360 |

符合手機 120 calls／120k、桌面 160 calls／300k 上限。切換時段重算陰影的單次影格另行檢查，不當作一般影格數字。實測裝置 DPR 為 1；另有高 DPR 上限檢查。完整數據見 `perf.json`。

執行 `npm run build`、`node tools/flow-check.mjs`、`node tools/city-lab-check.mjs`、`node tools/city-lab-v2-check.mjs`。全站回歸 87 路由、130 組視窗、106 張截圖、1,221 項檢查通過。模型另檢查 35 組地標近景、實際 canvas 點選、卡片與標籤、三時段固定材質、背景暫停、手機操作、無 JS／WebGL fallback、縮放尺寸切換和 console error。最終逐套退出碼與時間以 `outputs/city-lab/v5/test-results.json` 為準。

首頁與 city-lab 在 320／390／1440 無水平溢位。迎王樹狀圖不渲染。`home3d/` 全部原始檔與海報 SHA-256 保持不變；map、牌樓、正殿原始碼保持不變。首頁 HTML 只有既有共用打包流程產生的 module 路徑更新。

獨立視覺與實作完整性審查已通過；依外部 FIX 調整為桌機底座寬約 87.6%，手機拉近取景並允許外緣裁切，仍顯示東隆宮、海岸與港口；全景按鈕回到起始視角。通用廟改為主殿加前廊低坡屋頂，名稱統一「汕尾仔舊嘉蓮宮」，夜間加入少量共用材質暖窗與街燈。9 張指定審核圖片、地標清單與 JSON 證據放在 `outputs/city-lab/v5/`，不納入提交。外部審核 `REVIEW.txt` 第一行為 GO 才可提交、push 和 PUBLIC 部署。

## 驗證限制

測試使用本機 Chrome／SwiftShader 與觸控模擬，未測實體手機 GPU 或 Safari，不宣稱 60fps。LSP 回報 TypeScript language server 未安裝且先前已拒絕安裝；使用 Node 語法檢查、esbuild 與瀏覽器實際執行驗證，不宣稱 LSP 診斷通過。既有字型缺字使用瀏覽器 fallback，本輪未修改全站字型。

修正過程另重現零高度容器的投影錯誤；resize 與 render 現在於零尺寸暫停。相同重現步驟修正前 648 筆 SVG NaN console errors、修正後 0，已納入 city-lab-check。
