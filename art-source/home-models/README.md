# 首頁立體地標模型

2026-10-25，為本專案原創的示意 SVG 插畫。不是照片描摹，也不是實際宮廟建築測繪；屋頂、門窗、人物服飾僅用來辨認題材。七角頭的屋頂／匾額配色是介面識別，不代表實際屋頂或神職、轎班服色。原有原稿素材未更動。

色票沿用 DESIGN.md：和紙白、墨灰、珊瑚、暖黃、粉藍、草綠、淺米白。以曲線燕尾屋簷、前側立面、屋瓦筆畫、階梯、厚底座與淡墨陰影呈現 3/4 俯視立體感。東隆宮使用雙層屋簷、暖黃色與燈籠作為較華麗的專屬示意模型。

- 主檔：本資料夾的 17 個 SVG，192 × 176。
- 顯示衍生檔：`dist/assets/home-models/*.webp`，192 × 176，透明背景、無損。
- 重新產生：`node tools/build-home-models.mjs`。只使用專案已有的 sharp，不需外部服務。
- 素材總覽：加上 `--contact-sheet` 可產生 `../homepage-fix2/after/models.png`。
- 分類介面：`home-models.mjs` 的 `modelForPin(pin)`，回傳 name、src、width、height；HTML 載入與 lazy 策略由首頁元件負責。
- 模型預算：每個 WebP 不超過 25 KiB，生成器會檢查；本次共 141,998 bytes，最大 12,586 bytes。

類型包括東隆宮、七角頭七種識別配色、一般宮廟、王船、海岸與王船、武陣旗幟、將爺人物、鼓、鶴、樂師及一般小建築。陣團模型依既有名錄題材映射，不新增地點或座標。
